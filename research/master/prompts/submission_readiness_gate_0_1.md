## Gate objective

Determine whether the frozen Revision-0.4 manuscript package is ready to enter final submission preparation for PRE, and identify exactly what remains before an actual submission can be authorized.

Use current official APS/PRE author/submission instructions only where required to verify submission-format or metadata requirements. This is a journal-requirements check, not a new scientific literature search.

## Required audit categories

Classify every identified item as exactly one of:

1. `READY` — already complete and internally consistent;
2. `EDITORIAL FIX REQUIRED` — can be repaired from existing frozen content without scientific change;
3. `AUTHOR INPUT REQUIRED` — requires facts/preferences only the authors can supply or approve;
4. `EXTERNAL METADATA CHECK REQUIRED` — bibliographic/journal/repository metadata verification only;
5. `BLOCKER` — prevents submission readiness and cannot be resolved without a new MASTER decision.

Audit at minimum:

### A. Scientific/claim integrity

- frozen evidence ordering and verdicts;
- no unsupported universality/mathematical-novelty claims;
- Plasma/Neuro/Climate-A/Climate-B semantic distinctions;
- Climate-A geometry/performance pairing;
- Climate-B failure qualification;
- operational strong threshold labeled non-universal;
- `pre-specified and frozen before objective-separation evaluation` wording.

### B. Main manuscript completeness

- title, abstract, section architecture, conclusion;
- equation/symbol consistency;
- all Fig. 1–5 and Main Table 1 callouts/captions;
- Data Availability / Code Availability;
- supplement references;
- references cited in text versus bibliography/source metadata.

### C. Supplement completeness

- S1–S6 present and internally referenced;
- Supplement Table S1 and Fig. S5 placement;
- frozen machine-readable source paths;
- no new science introduced by separation from Draft 0.3.

### D. Figures/tables

- vector masters and previews exist;
- figure numbering and captions agree with Draft 0.4;
- Main Fig. 5 excludes Climate-B;
- PRE-facing file-format/production requirements are satisfied or explicitly listed as editorial fixes;
- no new scientific rerendering is performed beyond presentational conversion if later needed.

### E. Bibliography and external metadata

- normalize/check bibliographic metadata already cited;
- verify the final publication status of `Ogino2026` only as a metadata task;
- identify DOI/page/article-number gaps for already cited references;
- do not add new prior art or new novelty claims.

### F. Submission metadata requiring author input

Identify but do not decide:

- author names/order;
- affiliations;
- corresponding author;
- ORCIDs;
- acknowledgments/funding;
- conflict-of-interest declarations;
- author contributions if required/desired;
- OA route/APC/institutional agreement preference;
- cover-letter choices;
- suggested/excluded reviewers if applicable;
- repository archival deposition / DOI / release / license decisions.

### G. Repository/data/code packaging

- current public repository paths actually support the availability statements;
- identify whether a tagged release, archive DOI, CITATION metadata, or license is absent;
- absence is not automatically a scientific blocker; classify appropriately;
- do not create any DOI/license/release in this gate.

## Governance after the gate

If the verdict is `PASS` or `PASS WITH AUTHOR/METADATA ITEMS`, MASTER may subsequently release a narrowly scoped final-submission-preparation task. Do not perform that task in the same gate.

If `HOLD`, prepare only the minimal editorial-fix handoff needed; do not open new science.

**STOP — RETURN GATE RESULT TO MASTER.**
