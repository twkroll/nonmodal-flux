# T1 — Transport-generation order for signed observables

**Date:** 2026-09-01  
**Status:** proved in finite dimension; canonical T1 note; supporting theorem rather than standalone novelty claim

This note consolidates the earlier short-time transport-neutral result and the higher-order transport-generation hierarchy into one canonical theorem file.

## 1. Setup

Let

```math
\dot x = A x,\qquad x(0)=Bu,
```

with

```math
A\in\mathbb C^{n\times n},\qquad
Q=Q^\dagger\in\mathbb C^{n\times n},\qquad
B\in\mathbb C^{n\times m},
```

and positive input metric

```math
R_{\rm in}=R_{\rm in}^\dagger\succ0.
```

`Q` is a physics-derived signed transport form and may be indefinite. Define

```math
P_Q(T)=\int_0^T e^{A^\dagger t}Qe^{At}\,dt
```

and the whitened input-space operator

```math
K_Q(T)=R_{\rm in}^{-1/2}B^\dagger P_Q(T)BR_{\rm in}^{-1/2}.
```

For unit input cost the signed cumulative extremals are

```math
\gamma_+(T)=\lambda_{\max}(K_Q(T)),\qquad
\gamma_-(T)=\lambda_{\min}(K_Q(T)).
```

Introduce the Lyapunov derivative operator

```math
\mathcal L_A(X)=A^\dagger X+XA
```

and the projected generation matrices

```math
H_j=R_{\rm in}^{-1/2}B^\dagger\mathcal L_A^j(Q)BR_{\rm in}^{-1/2},
\qquad j=0,1,2,\ldots.
```

Each `H_j` is Hermitian.

## 2. Lemma — Exact analytic expansion

For finite-dimensional `A`,

```math
P_Q(T)=\sum_{j=0}^{\infty}
\frac{T^{j+1}}{(j+1)!}\,\mathcal L_A^j(Q),
```

and hence

```math
K_Q(T)=\sum_{j=0}^{\infty}
\frac{T^{j+1}}{(j+1)!}\,H_j.
```

### Proof

Set

```math
F(t)=e^{A^\dagger t}Qe^{At}.
```

Then

```math
F'(t)=A^\dagger F(t)+F(t)A,
```

so by induction

```math
F^{(j)}(0)=\mathcal L_A^j(Q).
```

Because the matrix exponential is entire, the Taylor series of `F` converges in every matrix norm. Termwise integration from `0` to `T`, followed by projection with `B` and whitening with `R_in`, gives the result. `\square`

## 3. Theorem T1-G — Transport-generation order

Assume that for some integer `\nu\ge0`,

```math
H_0=H_1=\cdots=H_{\nu-1}=0,
\qquad H_\nu\ne0.
```

Then, as `T\downarrow0`,

```math
K_Q(T)=\frac{T^{\nu+1}}{(\nu+1)!}H_\nu+O(T^{\nu+2}),
```

and therefore

```math
\gamma_+(T)=
\frac{T^{\nu+1}}{(\nu+1)!}\lambda_{\max}(H_\nu)
+O(T^{\nu+2}),
```

```math
\gamma_-(T)=
\frac{T^{\nu+1}}{(\nu+1)!}\lambda_{\min}(H_\nu)
+O(T^{\nu+2}).
```

We call

```math
\nu=\min\{j\ge0:H_j\ne0\}
```

the **transport-generation order** of the admissible input space for `(A,Q,B,R_in)`.

If the relevant extremal eigenvalue of `H_\nu` is simple, the corresponding normalized whitened optimal input converges to its eigenvector with angle `O(T)`. For a degenerate extremal eigenvalue only the limiting extremal eigenspace is intrinsic.

### Proof

The analytic expansion gives

```math
K_Q(T)=\frac{T^{\nu+1}}{(\nu+1)!}H_\nu+E(T),
\qquad \|E(T)\|_2=O(T^{\nu+2}).
```

Weyl's inequality for Hermitian matrices yields the eigenvalue expansions. After division by `T^{\nu+1}`, standard Hermitian eigenspace perturbation theory gives the eigenvector/eigenspace statement. `\square`

## 4. Corollary T1-N — Transport-neutral admissible inputs

The admissible input space is transport-neutral at the initial instant when

```math
B^\dagger Q B=0.
```

Equivalently, `H_0=0`. If

```math
H_1=
R_{\rm in}^{-1/2}B^\dagger(A^\dagger Q+QA)BR_{\rm in}^{-1/2}
\ne0,
```

then `\nu=1` and

```math
\gamma_+(T)=\frac{T^2}{2}\lambda_{\max}(H_1)+O(T^3),
```

```math
\gamma_-(T)=\frac{T^2}{2}\lambda_{\min}(H_1)+O(T^3).
```

At the instantaneous level,

```math
x(t)^\dagger Qx(t)
=t\,u^\dagger B^\dagger(A^\dagger Q+QA)Bu+O(t^2).
```

Thus the leading transport is generated by the dynamics rather than inserted as an initial optimal cross-phase.

For indefinite `Q`, `range(B)` can be a totally `Q`-isotropic subspace while `QB\ne0`; this is exactly what allows a nonzero first derivative of the signed observable.

## 5. Corollary T1-P — Difference from a positive-semidefinite output

If

```math
Q\succeq0,\qquad B^\dagger QB=0,
```

then

```math
Q^{1/2}B=0,
```

hence

```math
QB=0,\qquad B^\dagger Q=0,
```

and therefore `H_1=0`. The first possible nonzero projected term is

```math
B^\dagger\mathcal L_A^2(Q)B
=2B^\dagger A^\dagger QAB,
```

so

```math
K_Q(T)=
\frac{T^3}{3}
R_{\rm in}^{-1/2}B^\dagger A^\dagger QABR_{\rm in}^{-1/2}
+O(T^4).
```

The leading matrix is positive semidefinite.

### Interpretation

Initial neutrality has a structurally different consequence for a genuine indefinite signed transport form than for a positive-semidefinite energy/semi-norm. An indefinite flux can begin at cumulative order `T^2`; a positive-semidefinite output satisfying the same projected-null condition begins no earlier than `T^3`.

This is one mathematical reason to preserve Luelff-style physical cross terms rather than replace transport by sums of squared amplitudes.

## 6. Corollary T1-C — Coordinate invariance

For an invertible state-coordinate change

```math
x'=Sx,
```

transform

```math
A'=SAS^{-1},\qquad
Q'=S^{-\dagger}QS^{-1},\qquad
B'=SB.
```

Then

```math
\mathcal L_{A'}^j(Q')
=S^{-\dagger}\mathcal L_A^j(Q)S^{-1}
```

for every `j`, and consequently

```math
B'^\dagger\mathcal L_{A'}^j(Q')B'
=B^\dagger\mathcal L_A^j(Q)B.
```

Therefore `H_j`, the generation order `\nu`, and the leading signed extremal coefficients are invariant under invertible physical state-coordinate changes.

## 7. Stable 2 x 2 analytic witness

Take

```math
A=\begin{bmatrix}-1&0\\ \kappa&-2\end{bmatrix},
\qquad
Q=\frac12\begin{bmatrix}0&1\\1&0\end{bmatrix},
\qquad
B=\begin{bmatrix}1\\0\end{bmatrix},
\qquad R_{\rm in}=1.
```

For `\kappa\ne0`, `A` is spectrally stable and nonnormal. The admissible initial state is transport-neutral:

```math
B^TQB=0.
```

But

```math
B^T(A^TQ+QA)B=\kappa.
```

For unit input,

```math
x_1(t)=e^{-t},\qquad
x_2(t)=\kappa(e^{-t}-e^{-2t}),
```

so

```math
q(t)=x_1(t)x_2(t)
=\kappa(e^{-2t}-e^{-3t})
```

and

```math
J_Q(T)=
\kappa\left[
\frac{1-e^{-2T}}{2}-\frac{1-e^{-3T}}{3}
\right]
=\frac{\kappa}{2}T^2+O(T^3).
```

This is the canonical analytic benchmark for the later numerical core. It is not itself a plasma model or a novelty demonstration.

## 8. Scientific status

### Established by T1

1. Exact finite-dimensional short-time hierarchy for the signed cumulative observable.
2. A precise transport-neutrality condition eliminating the trivial `O(T)` contribution.
3. A generation-order diagnostic determined by projected Lyapunov derivatives.
4. Coordinate invariance of the projected generation hierarchy.
5. A structural onset-order distinction between indefinite signed transport and positive-semidefinite outputs.

### Not established by T1

1. Abstract mathematical novelty of the hierarchy.
2. Existence of a physically justified transport-neutral plasma input space for the final convention.
3. A robust finite-horizon difference between free-energy- and transport-optimal perturbations.
4. An infinite-dimensional extension.

T1 is therefore retained as a supporting theorem and as a stringent analytic/numerical validation target. The likely paper-level contribution must combine it with physics-derived flux operators, T2/T3 balance structure, T4 energy/transport separation, and a nontrivial plasma result.
