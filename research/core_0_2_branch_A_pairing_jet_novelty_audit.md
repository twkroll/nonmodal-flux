## 1. Exact information hierarchy

Introduce the bivariate restricted quadratic kernel

```math
\mathcal K_Q(s,t)
:=B^\dagger e^{A^\dagger s}Qe^{At}B.
```

Its Taylor expansion at `(0,0)` is

```math
\mathcal K_Q(s,t)
=\sum_{p,q\ge0}\frac{s^p t^q}{p!q!}M_{p,q}.
```

Hence

```math
\boxed{
M_{p,q}
=\partial_s^p\partial_t^q\mathcal K_Q(0,0).
}
```

Thus the full two-index family `{M_{p,q}}` is equivalent to the full bivariate
jet of `\mathcal K_Q` at the origin.

The restricted Gram curve is the diagonal restriction

```math
G_Q(t)=\mathcal K_Q(t,t).
```

Collecting equal total degrees gives

```math
G_Q(t)
=\sum_{j\ge0}\frac{t^j}{j!}S_j,
```

so

```math
\boxed{
S_j=G_Q^{(j)}(0).
}
```

Since

```math
H_j=R_{\rm in}^{-1/2}S_jR_{\rm in}^{-1/2}
```

and `R_in>0`, the sequences `{H_j}` and `{S_j}` have exactly the same
zero/nonzero pattern. In particular, the generation order does not depend on
the choice of positive-definite input metric `R_in`.

### Information retained and lost

The map

```math
\{M_{p,q}:p+q=j\}
\longmapsto
S_j
```

is a binomially weighted anti-diagonal contraction. It is generally not
injective.

For Hermitian `Q`,

```math
M_{q,p}=M_{p,q}^\dagger.
```

At the first two orders,

```math
S_1=M_{0,1}+M_{0,1}^\dagger
=2\operatorname{Herm}M_{0,1},
```

and

```math
S_2
=M_{0,2}+2M_{1,1}+M_{2,0}
=2\operatorname{Herm}M_{0,2}+2M_{1,1}.
```

Thus already at first order the skew-Hermitian part of `M_{0,1}` is lost, and
from second order onward different Hermitian contributions can cancel as well.
The earlier `2 x 2` counterexample is a concrete realization of this kernel.

Therefore

```text
full bivariate jet  <=>  full {M_pq}
           |
           | diagonal restriction / anti-diagonal contraction
           v
univariate jet of G_Q  <=>  {S_j}  <=> zero-pattern of {H_j}
```

but the reverse reconstruction from `{S_j}` or `G_Q` to `{M_{p,q}}` is false
in general.

## 2. Extension to nu = infinity

The natural extended definition is

```math
\boxed{
\nu:=\inf\{j\ge0:H_j\ne0\}\in\mathbb N_0\cup\{\infty\}.
}
```

Equivalently, set `nu=infinity` when all `H_j` vanish.

Because `G_Q(t)` is an entire matrix-valued function, the following statements
are equivalent:

```math
\nu=\infty,
```

```math
H_j=0\quad\forall j\ge0,
```

```math
S_j=0\quad\forall j\ge0,
```

```math
G_Q^{(j)}(0)=0\quad\forall j\ge0,
```

and

```math
\boxed{
G_Q(t)\equiv0.
}
```

Let

```math
\mathcal W(t)=\operatorname{range}(e^{At}B).
```

Then `G_Q(t)=0` is equivalent to `Q` vanishing on all pairings of vectors in
`\mathcal W(t)`. Hence

```math
\boxed{
\nu=\infty
\iff
\mathcal W(t)\text{ is totally }Q\text{-isotropic for every }t.
}
```

This does **not** imply that the bivariate kernel vanishes or that every
`M_{p,q}` is zero. The earlier normal `2 x 2` example has `nu=infinity` while
`M_{0,1}=i` is nonzero. Thus the moving subspace can remain instantaneously
isotropic while cross-time/two-index pairings remain nontrivial.

### Finite-dimensional stopping test

Let

```math
\mathscr V_Q
=\operatorname{span}\{Q,\mathcal L_A(Q),\mathcal L_A^2(Q),\ldots\}
```

and let `d` be the degree of the minimal polynomial of `\mathcal L_A` relative
to the cyclic vector `Q` (equivalently the Krylov dimension generated by `Q`
under `\mathcal L_A`). In complex matrix space, `d<=n^2`; in the real
symmetric setting the analogous dimension is at most `n(n+1)/2`.

By the resulting linear recurrence,

```math
S_0=\cdots=S_{d-1}=0
\quad\Longrightarrow\quad
S_j=0\ \forall j,
```

so either `nu<d` or `nu=infinity`. This is standard finite-dimensional
observation/Krylov structure rather than a new CORE theorem.

## 3. Lifted linear representation

Vectorization makes the standard nature of the hierarchy explicit. With
column-major `vec`,

```math
\operatorname{vec}(\mathcal L_A(X))
=\mathscr A_Q\operatorname{vec}(X),
```

where

```math
\mathscr A_Q
=I\otimes A^\dagger+A^T\otimes I.
```

Moreover,

```math
\operatorname{vec}(B^\dagger X B)
=(B^T\otimes B^\dagger)\operatorname{vec}(X).
```

Therefore

```math
\boxed{
\operatorname{vec}(S_j)
=(B^T\otimes B^\dagger)\mathscr A_Q^j\operatorname{vec}(Q).
}
```

Thus `{S_j}` is a one-index output/Markov-type sequence of a lifted linear
system on matrix space, with `vec(Q)` as the seed/initial state and
`B^T\otimes B^dagger` as the output map. The first nonzero `S_j` is therefore
a standard vanishing-order / observability-index type quantity in that lifted
representation.

This does not make the physical CORE interpretation unimportant, but it removes
the basis for claiming the algebraic hierarchy itself as a new Krylov or
relative-degree theorem.

## 4. Rank and geometric interpretation

The zero/nonzero sequence is unchanged by removing redundant columns of `B`.
If

```math
B=\widehat B C
```

with `\widehat B` full column rank and `C` full row rank, then

```math
S_j=C^\dagger\widehat S_j C,
```

and a right inverse of `C` shows

```math
S_j=0\iff\widehat S_j=0.
```

Hence `nu` depends on the represented admissible state subspace and its
embedding under the dynamics, not on redundant input coordinates.

For full-column-rank `B`, the curve

```math
\mathcal W(t)=e^{At}\operatorname{range}(B)
```

is a curve in a Grassmannian. If `Q` is nondegenerate Hermitian and
`B^dagger Q B=0`, then `\mathcal W(0)` lies in the corresponding isotropic
Grassmannian. In this language, finite `nu` is exactly the order of vanishing of
a local defining Gram map along the orbit, i.e. an order-of-contact
interpretation; `nu=infinity` means the orbit stays inside the isotropic locus.

This is a useful CORE interpretation, but mathematically it is a reformulation
of the diagonal Gram jet, not presently a distinct theorem beyond standard
contact/jet geometry.

For a Hermitian form with inertia `(n_+,n_-,n_0)`, a totally isotropic subspace
can have dimension at most

```math
n_0+\min(n_+,n_-),
```

so a full-rank transport-neutral input map of rank `r` requires the corresponding
Witt-index dimension bound. This is standard indefinite-inner-product geometry.

## 5. Strong additional assumptions that remove cancellation

These regimes are mathematically useful, but they do not rescue a new general
Branch-A theorem.

### 5.1 Q-selfadjoint generator

If

```math
A^\dagger Q=QA,
```

then

```math
(A^\dagger)^pQ=QA^p
```

and therefore every pairing on a fixed anti-diagonal is the same one-index
quantity:

```math
M_{p,q}=B^\dagger QA^{p+q}B.
```

Consequently

```math
\boxed{
S_j=2^j B^\dagger QA^jB.
}
```

In this special indefinite-inner-product regime, the generation order really
can be read from a one-index moment sequence.

### 5.2 Q-skew-adjoint generator

If

```math
A^\dagger Q=-QA,
```

then

```math
M_{p,q}=(-1)^pB^\dagger QA^{p+q}B
```

and

```math
S_j=(1-1)^jB^\dagger QA^jB.
```

Hence

```math
S_j=0\quad(j\ge1).
```

If also `B^dagger Q B=0`, then `nu=infinity`. The previous `2 x 2`
counterexample lies exactly in this regime, so its cancellation is not an
accident but a standard `Q`-skew-adjoint symmetry.

### 5.3 Positive-semidefinite output as a boundary case

If `Q>=0` and `B^dagger Q B=0`, then `Q^{1/2}B=0`. Let

```math
r=\min\{k\ge0:Q^{1/2}A^kB\ne0\}.
```

If no such `r` exists, `nu=infinity`. Otherwise all pairings with `p<r` or
`q<r` vanish. On the first possible nonzero anti-diagonal `p+q=2r`, only the
central term survives, giving

```math
\boxed{
\nu=2r,
\qquad
S_{2r}=\binom{2r}{r}(A^rB)^\dagger Q(A^rB)\ne0.
}
```

This recovers and extends the earlier PSD onset-order observation, but it is a
standard Gram-factorization consequence rather than a signed-CORE novelty.

## 6. Prior-art boundary

The targeted literature check changes the Branch-A novelty assessment
substantially.

### Successive Lie derivatives of quadratic outputs are already explicit

Berkane, Theodosis, Hamel, and Dimarogonas, *State Estimation for Linear
Systems With Quadratic Outputs*, IEEE Control Systems Letters 7 (2023),
3872--3877, DOI 10.1109/LCSYS.2023.3343705, define the Lyapunov operator

```math
\mathcal L_A(X)=XA+A^T X
```

for symmetric quadratic-output matrices, state that successive Lie derivatives
are represented by `\mathcal L_A^{[k]}(Q)`, and exploit the finite-dimensional
invariant observation space generated by those iterates. Their earlier
single-output work also writes the recursion and the binomial expansion
explicitly.

This is the real-symmetric analogue of the Hermitian CORE hierarchy and already
covers the central repeated-Lyapunov-derivative algebra.

### Bivariate quadratic kernels / transfer functions are established

Gosea and Gugercin, *Data-Driven Modeling of Linear Dynamical Systems with
Quadratic Output in the AAA Framework*, Journal of Scientific Computing 91
(2022), formulate a two-variable quadratic transfer function for linear systems
with quadratic output. The quadratic part is represented through two resolvent
factors and is intrinsically bivariate.

The time-domain kernel corresponding to that structure contains two independent
time variables and therefore the same type of two-index moments represented
here by `M_{p,q}`.

### Krylov moment matching for quadratic outputs is established

Yan-Ping Bu, *Krylov subspace model order reduction of linear dynamical systems
with quadratic output*, Transactions of the Institute of Measurement and
Control 47 (2025), 827--838, DOI 10.1177/01423312241257298, explicitly uses the
two-variable quadratic transfer function, Krylov subspaces, and moment matching,
including one-sided and two-sided projection variants.

Ionescu, Iftime, and Necoara, *Moment matching-based model reduction for systems
with linear quadratic output*, CDC 2025 proceedings (published 2026), likewise
develop a time-domain moment-matching framework for LQO systems.

### Relative degree and Lie derivatives

Classical relative degree is not literally identical to `nu`: relative degree
asks when an external control input first appears in successive output
derivatives. Here `nu` asks when a quadratic output, restricted to a prescribed
initial-condition subspace, first becomes nonzero under autonomous evolution.
Nevertheless, both are standard successive-Lie-derivative/vanishing-order
constructions. After the matrix-space lift above, `nu` is directly an
observability/Markov-type delay index.

## 7. Novelty assessment

The following pieces are therefore **not** supportable as new CORE mathematics:

1. the repeated Lyapunov-operator hierarchy itself;
2. its binomial expansion;
3. the full two-index quadratic moment family as such;
4. the bivariate-kernel viewpoint as such;

6. the interpretation of the first nonzero derivative as a generic
   relative-degree/observability-like index;
7. finite-dimensional termination/recurrence of the lifted hierarchy.

What remains CORE-specific at this point is primarily an **interpretive
combination**:

- `Q` is a physics-derived Hermitian **signed/indefinite** transport form rather
  than a generic quadratic sensor/output;
- the admissible initial space is deliberately chosen to be `Q`-isotropic
  (`B^dagger Q B=0`);
- positive and negative finite-horizon transport extremals are retained;
- the order of the diagonal Gram jet is interpreted as the order at which the
  dynamics leave instantaneous transport neutrality;
- this object is tied to the independent positive metric `M`, physical balance,
  and later T3/T4 transport statements.

The targeted search did not establish that this exact physical interpretation
has already appeared. But no nontrivial Branch-A theorem beyond established
quadratic-output/Lie-derivative/moment machinery has survived the present audit.
