## Provisional Gate-0 conclusion

A standalone P1 cannot be justified by quadratic outputs, Gramians, nonmodal growth, or objective-dependent optimals alone.

The most promising axis is:

> **constrained dynamically generated signed transport** — an independent positive disturbance metric, a physics-derived indefinite transport form, a physically admissible/transport-neutral input space, finite-horizon signed extremals, and a physical energy/free-energy balance.

## First theorem candidate: transport generation from a neutral input space

For constant `A`,

```math
P_Q(T) = \int_0^T e^{A^\dagger t} Q e^{At}\,dt.
```

Expanding at small `T`,

```math
P_Q(T)
= TQ + \frac{T^2}{2}(A^\dagger Q + QA)
+ \frac{T^3}{6}\left((A^\dagger)^2Q + 2A^\dagger QA + QA^2\right)
+ O(T^4).
```

If the admissible input space is initially transport-neutral,

```math
B^\dagger Q B = 0,
```

then

```math
B^\dagger P_Q(T) B
= \frac{T^2}{2} B^\dagger(A^\dagger Q+QA)B + O(T^3).
```

With

```math
H_1 = R_{in}^{-1/2} B^\dagger(A^\dagger Q+QA)B R_{in}^{-1/2},
```

the leading signed extremal gains should be governed by the largest and smallest eigenvalues of `H_1`, subject to the usual care for degeneracies and higher-order cancellation.

**Interpretation:** the `O(T)` contribution is removed by construction. Any leading transport is generated by the dynamics rather than inserted as an optimal initial cross-phase.

## Critical falsification tests before sweeps

1. `Q = M` special case.
2. `B† Q B = 0`: verify disappearance of the `O(T)` term and the predicted `O(T^2)` coefficient.
3. Physically normal replacement operator: determine which effect is specifically tied to nonnormal geometry.
4. Drive/gradient `-> 0`: the transport-generating mechanism must vanish or remain physically explainable.
5. Symmetrized coupling control.
6. Coordinate/scaling transformations: physical gains must remain invariant.
7. Full input space vs. transport-neutral space: quantify the contribution of trivial initial transport phase.
