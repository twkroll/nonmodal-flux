# D10-ZF — prescribed-zonal-flow HW linearization and perturbation-energy balance

**Date:** 2026-09-02  
**Status:** continuous derivation frozen; no zonal-flow profile amplitude, radial discretization, or new damping calibration chosen yet

## Purpose and scope

Decision D10-ZF selects the next coupled plasma robustness test: linearize the frozen D2-A / modified Hasegawa-Wakatani dynamics about a prescribed zonal potential `Phi(x)`, initially with no zonal-density perturbation `N(x)`. The coupling must be produced by the continuous PDE before discretization. No arbitrary off-diagonal block is admissible.

This note performs only the continuous step. It derives

1. the linearized drift-wave equations at fixed nonzero `k_y`;
2. the physical perturbation-energy metric and outward particle-flux observable;
3. the additional signed mean-flow energy-exchange channel;
4. the sideband coupling produced by a nonuniform zonal flow;
5. the operator balance that a later discretization must reproduce.

No choice of zonal-flow amplitude, sideband count, radial grid, or pilot horizon is made here.

## 1. Source-level baseline and D2-A sign convention

The modified HW equations of Numata, Ball and Dewar use the nonlinear advection bracket and exclude zonal components from the resistive coupling. In the already frozen D2-A orientation,

```math
v_E=e_z\times\nabla\phi,
\qquad
v_x=-\partial_y\phi,
```

and

```math
\{a,b\}=a_x b_y-a_y b_x.
```

For the non-zonal sector relevant here, the equations without an additional perpendicular-dissipation model are

```math
\partial_t\zeta+\{\phi,\zeta\}=C(\phi-n),
\qquad
\zeta=\nabla^2\phi,
```

```math
\partial_t n+\{\phi,n\}
=C(\phi-n)-\kappa\,\partial_y\phi.
```

These signs reduce, on a homogeneous background and a Fourier mode proportional to `exp(i k_x x+i k_y y)`, to the accepted D2-A matrix

```math
L_k=
\begin{pmatrix}
-C/k^2&C/k^2\\
C-i\kappa k_y&-C
\end{pmatrix}.
```

Numata et al. also identify the continuous HW energy as the sum of density and `E x B` kinetic contributions and the radial density flux as the cross-phase term generated by `v_x=-partial_y phi`. Zhu, Zhou and Dodin subsequently analyze modified-HW drift waves about prescribed zonal states `U(x)` and `N(x)` and show explicitly that the drift-wave operator depends on the zonal velocity and its curvature `U''`. Those literature results motivate the present background choice; the balance below is derived directly in the D2-A convention rather than imported from a different normalization.

## 2. Prescribed zonal state

Take

```math
\phi(x,y,t)=\Phi(x)+\varphi(x,y,t),
\qquad
n(x,y,t)=\eta(x,y,t),
```

with

```math
U(x)=\Phi'(x).
```

For the modified HW model, a purely zonal `Phi(x)` is excluded from the non-zonal resistive coupling. With no separately imposed zonal damping, `Phi(x)` is a stationary background because

```math
\{\Phi,\Phi''\}=0.
```

Thus the present prescribed-background linearization does not require inventing a compensating forcing term at this stage.

We deliberately set the zonal density `N(x)=0` in D10-ZF. A nonzero `N` is a legitimate later extension and would replace the constant density-gradient drive locally by an effective gradient involving `N'(x)`, but it is not needed to produce physical mode coupling.

## 3. Continuous linearization

Write

```math
\zeta=\Phi''+\nabla^2\varphi.
```

Keeping only terms linear in `(varphi,eta)` gives

```math
\{\Phi,\nabla^2\varphi\}
=U\,\partial_y\nabla^2\varphi,
```

and

```math
\{\varphi,\Phi''\}
=-U''\,\partial_y\varphi.
```

Therefore the linearized vorticity equation is

```math
\boxed{
\partial_t\nabla^2\varphi
+U\,\partial_y\nabla^2\varphi
-U''\,\partial_y\varphi
=C(\varphi-\eta)
}
```

and the linearized density equation is

```math
\boxed{
\partial_t\eta
+U\,\partial_y\eta
=C(\varphi-\eta)-\kappa\,\partial_y\varphi.
}
```

The `U` terms are advection by the zonal flow, while the `U''` term is the vorticity-gradient/curvature contribution. These are not fitted matrix entries.

### Fixed nonzero poloidal wavenumber

Because the background is independent of `y`, different `k_y` sectors remain independent. For

```math
\varphi(x,y,t)=\hat\varphi(x,t)e^{i k_y y},
\qquad
\eta(x,y,t)=\hat\eta(x,t)e^{i k_y y},
\qquad k_y\ne0,
```

define

```math
\Delta_k=\partial_x^2-k_y^2.
```

Then

```math
\boxed{
\partial_t\Delta_k\hat\varphi
+i k_y U\,\Delta_k\hat\varphi
-i k_y U''\hat\varphi
=C(\hat\varphi-\hat\eta)
}
```

and

```math
\boxed{
\partial_t\hat\eta
+i k_y U\hat\eta
=C(\hat\varphi-\hat\eta)-i\kappa k_y\hat\varphi.
}
```

For fixed prescribed `U(x)` this is an autonomous linear initial-value problem. Hence after a structure-preserving radial discretization it will again have the form

```math
\dot z=A_U z
```

with a constant matrix `A_U`, so the existing finite-horizon T1--T4 machinery remains applicable.

## 4. Physical perturbation energy

Before discretization, retain the D2-A physical perturbation energy

```math
\boxed{
E_{\rm pert}
=\frac12\int
\left(
|\partial_x\hat\varphi|^2
+k_y^2|\hat\varphi|^2
+|\hat\eta|^2
\right)\,dx.
}
```

Equivalently,

```math
E_{\rm pert}
=\frac12\int
\left[-\hat\varphi^*\Delta_k\hat\varphi
+|\hat\eta|^2\right]dx
```

under periodic radial boundary conditions (or boundary conditions that remove the integration-by-parts surface term).

This expression, not a post-hoc weighted Euclidean norm, must generate the discrete metric `M`.

## 5. Physical outward particle flux

The radial velocity is still

```math
v_x=-\partial_y\varphi.
```

In the fixed-`k_y` complex-amplitude convention aligned with D2-A, the signed outward particle flux is

```math
\boxed{
\Gamma
=k_y\int \operatorname{Im}(\hat\eta^*\hat\varphi)\,dx.
}
```

This remains the target transport observable. The zonal-flow coupling does not redefine `Gamma` and does not permit replacing it by an amplitude sum.

After discretization this expression must become a Hermitian indefinite quadratic form

```math
\Gamma=z^\dagger Q_\Gamma z
```

with all radial quadrature/mass weights inherited from the continuous integral.

## 6. Mean-flow energy exchange

Differentiate `E_pert`, substitute the two linearized equations, and integrate by parts in `x`. The `U''` contribution proportional to `|varphi|^2` is purely imaginary in the complex-amplitude energy derivative and therefore contributes no real energy change. The nonuniform advection term produces the Reynolds-stress exchange

```math
\boxed{
\mathcal P_U
=k_y\int U'(x)\,
\operatorname{Im}
\left(\hat\varphi^*\partial_x\hat\varphi\right)dx.
}
```

Equivalently, if the modal Reynolds stress is written as

```math
\Pi_{xy}=\operatorname{Re}(v_x^*v_y),
\qquad
v_x=-i k_y\hat\varphi,
\quad
v_y=\partial_x\hat\varphi,
```

then

```math
\boxed{
\mathcal P_U=-\int U'(x)\Pi_{xy}(x)\,dx.
}
```

Thus `P_U>0` means that the perturbations gain energy from the prescribed zonal flow, while `P_U<0` means that perturbations return energy to that background reservoir.

This is a signed physical energy-exchange channel, not the radial particle-flux objective. It must remain separate from `Q_Gamma`.

## 7. Exact continuous perturbation-energy balance

The resistive-coupling contributions combine exactly as in the homogeneous D2-A case:

```math
-C\int|\hat\varphi-\hat\eta|^2dx.
```

The density-gradient term gives `kappa Gamma`. Hence

```math
\boxed{
\frac{dE_{\rm pert}}{dt}
=
\kappa\Gamma
+\mathcal P_U
-C\int|\hat\varphi-\hat\eta|^2\,dx.
}
```

This is the central D10-ZF balance.

Two consequences are important.

First, the old homogeneous identity does **not** survive unchanged: the prescribed mean flow is a second signed source/sink channel. Second, the target particle flux remains physically distinct from that channel. A perturbation can therefore exchange energy with the zonal flow without that exchange itself being the particle-transport objective.

If a later perpendicular-dissipation operator is introduced, its contribution must be derived and appended as an additional nonnegative sink whenever the chosen operator is dissipative in the physical perturbation metric. No damping is inserted in D10-ZF by default.

## 8. Discrete operator identity required by D5

Let a later radial discretization produce

```math
E_{\rm pert}=\frac12 z^\dagger M z,
\qquad
\Gamma=z^\dagger Q_\Gamma z,
\qquad
\mathcal P_U=z^\dagger Q_U z,
```

where `M=M^dagger>0`, and `Q_Gamma` and `Q_U` are Hermitian signed forms derived from their respective continuous expressions.

Let `D_C` denote the positive-semidefinite discrete form satisfying

```math
\frac12 z^\dagger D_C z
=C\int|\hat\varphi-\hat\eta|^2dx.
```

Then the assembled generator must satisfy, up to discretization error,

```math
\boxed{
A_U^\dagger M+M A_U
=2\kappa Q_\Gamma+2Q_U-D_C.
}
```

This is now a genuine multichannel balance of the type addressed abstractly by T3. The coefficients are fixed by the physical energy balance; they are not tuning weights.

A later implementation test must verify this matrix identity before any finite-horizon optimizer is interpreted.

## 9. How a sinusoidal zonal flow couples radial Fourier sidebands

To make the coupling mechanism explicit without selecting its amplitude, consider symbolically

```math
U(x)=u\cos(q_Zx).
```

Then

```math
U''=-q_Z^2U.
```

The vorticity-side coupling operator at fixed `k_y` is

```math
i k_y\left(U\Delta_k-U''\right)
=i k_y U\left(\Delta_k+q_Z^2\right).
```

For a radial harmonic `exp(i k_x x)`, multiplication by `U` generates the neighboring harmonics

```math
k_x\longrightarrow k_x\pm q_Z.
```

More explicitly, the coefficient entering the vorticity equation from an input harmonic with

```math
K^2=k_x^2+k_y^2
```

is proportional to

```math
\frac{i k_y u}{2}\left(q_Z^2-K^2\right)
```

toward each adjacent sideband. The density-advection term `i k_y U eta` generates the same sideband shifts, with its own physically fixed coefficient.

Therefore a sinusoidal zonal flow removes the direct-sum structure of Branch M automatically. A two-mode closed block would generally be artificial because the same mechanism continues the sideband ladder. The next discretization must make its truncation or radial grid explicit and test convergence.

## 10. Limiting checks

The derivation has several immediate falsification checks.

### Zero zonal flow

For

```math
U=0,
```

we have `P_U=0`, radial Fourier modes decouple, and the D2-A homogeneous equations and balance are recovered.

### Uniform zonal velocity

For constant `U`,

```math
U'=U''=0.
```

The background contributes only a Doppler shift `i k_y U`; it neither couples radial modes nor exchanges perturbation energy. Thus physical coupling requires spatial variation of the zonal flow.

### Nonuniform zonal flow

For `U' != 0`, `P_U` is generally indefinite. Strict energy contraction can no longer be inferred from the homogeneous sink alone; it must be checked for the chosen profile after assembly.

## 11. Interpretation for T1--T4 and T3

For a fixed prescribed profile, the problem remains autonomous, so no new propagator theory is required merely to run the coupled pilot. T1--T4 can be tested with the new `A_U`, `M`, `Q_Gamma`, and an explicitly chosen admissible input map `B`.

However, D10-ZF makes T3 materially more relevant to the plasma application. The physical perturbation-energy balance contains at least two signed channels,

```math
Q_\Gamma
\quad\text{and}\quad
Q_U,
```

plus the resistive sink. The total balance therefore cannot by itself identify or replace either channel. This is precisely why the independently derived particle-flux observable must remain the optimization target.

The homogeneous-shear/shearing-wave branch remains separate. When `U(x)=Sx` is represented by a time-dependent shearing wave with `k_x(t)`, the reduced generator becomes nonautonomous; that is the later point at which a genuine extension of the underlying transport-generation theory is expected.

## 12. Next implementation gate

The next step should still precede any optimizer calculation:

1. choose a periodic radial representation at one fixed nonzero `k_y`;
2. derive the discrete `M`, `Q_Gamma`, and `Q_U` from the three continuous quadratic forms above;
3. assemble `A_U` from the linearized PDE, not from a guessed block coupling;
4. verify Hermiticity/positivity and the exact multichannel balance numerically;
5. verify convergence as radial resolution/sideband count is increased;
6. only then choose one prescribed zonal profile and test spectral stability, energy behavior, transport neutrality, and energy-versus-transport optimizer separation.

No zonal-flow amplitude is frozen before these structural checks.
