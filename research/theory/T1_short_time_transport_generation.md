# T1 — Short-time generation of signed transport

**Date:** 2026-09-01  
**Status:** proved in finite dimension; supporting theorem, not yet a standalone novelty claim

## 1. Setup

Let

```math
\dot x = A x, \qquad x(0)=Bu,
```

with

- `A in C^{n x n}`,
- `Q = Q† in C^{n x n}` a physics-derived signed transport form,
- `B in C^{n x m}` the admissible-input map,
- `R = R† > 0 in C^{m x m}` the positive input metric.

The instantaneous signed transport and its finite-horizon accumulation are

```math
q(t;u)=x(t)^\dagger Qx(t),
```

```math
J_Q(T;u)=\int_0^T q(t;u)\,dt.
```

Define

```math
P_Q(T)=\int_0^T e^{A^\dagger t}Qe^{At}\,dt
```

and the whitened input-space operator

```math
K_Q(T)=R^{-1/2}B^\dagger P_Q(T)BR^{-1/2}.
```

The signed extremal values for unit input cost are

```math
\gamma_+(T)=\max_{u^\dagger Ru=1}J_Q(T;u)=\lambda_{\max}(K_Q(T)),
```

```math
\gamma_-(T)=\min_{u^\dagger Ru=1}J_Q(T;u)=\lambda_{\min}(K_Q(T)).
```

Here `R^{-1/2}` denotes the Hermitian positive-definite inverse square root.

## 2. Lyapunov derivative operator

Introduce the linear operator on matrices

```math
\mathcal L_A(X)=A^\dagger X+XA.
```

Repeated application gives

```math
\mathcal L_A^2(Q)=(A^\dagger)^2Q+2A^\dagger QA+QA^2,
```

and, more generally,

```math
\mathcal L_A^j(Q)
=\sum_{r=0}^j {j\choose r}(A^\dagger)^r Q A^{j-r}.
```

Define the projected, whitened transport-generation matrices

```math
H_j=R^{-1/2}B^\dagger \mathcal L_A^j(Q)B R^{-1/2}.
```

Each `H_j` is Hermitian.

## 3. Lemma: exact analytic expansion

For every finite-dimensional `A` and Hermitian `Q`,

```math
P_Q(T)=\sum_{j=0}^{\infty}
\frac{T^{j+1}}{(j+1)!}\,\mathcal L_A^j(Q),
```

with convergence in every matrix norm. Consequently,

```math
K_Q(T)=\sum_{j=0}^{\infty}
\frac{T^{j+1}}{(j+1)!}\,H_j.
```

### Proof

Set

```math
F(t)=e^{A^\dagger t}Qe^{At}.
```

Differentiation gives

```math
F'(t)=A^\dagger F(t)+F(t)A,
```

so by induction

```math
F^{(j)}(0)=\mathcal L_A^j(Q).
```

The matrix exponential is entire, hence `F` has the globally convergent Taylor series

```math
F(t)=\sum_{j=0}^{\infty}\frac{t^j}{j!}\mathcal L_A^j(Q).
```

Termwise integration from `0` to `T` gives the result. Premultiplication and postmultiplication by the fixed matrices defining `K_Q` gives the second expansion. ∎

## 4. Theorem T1-G: transport-generation order

Assume that for some integer `nu >= 0`,

```math
H_0=H_1=\cdots=H_{\nu-1}=0,
\qquad H_\nu\ne0.
```

Then, as `T -> 0+`,

```math
K_Q(T)=\frac{T^{\nu+1}}{(\nu+1)!}H_\nu
+O(T^{\nu+2})
```

in operator norm, and therefore

```math
\gamma_+(T)=\frac{T^{\nu+1}}{(\nu+1)!}\lambda_{\max}(H_\nu)
+O(T^{\nu+2}),
```

```math
\gamma_-(T)=\frac{T^{\nu+1}}{(\nu+1)!}\lambda_{\min}(H_\nu)
+O(T^{\nu+2}).
```

If the relevant extremal eigenvalue of `H_nu` is simple, the corresponding normalized whitened optimal input converges to its eigenvector with angle `O(T)`. For a degenerate extremal eigenvalue, only the associated extremal eigenspace should be interpreted.

### Proof

The series lemma gives

```math
K_Q(T)=\frac{T^{\nu+1}}{(\nu+1)!}H_\nu+E(T),
\qquad \|E(T)\|_2=O(T^{\nu+2}).
```

Because `K_Q(T)` and `H_nu` are Hermitian, Weyl's eigenvalue perturbation inequality implies

```math
\left|\lambda_k(K_Q(T))-
\frac{T^{\nu+1}}{(\nu+1)!}\lambda_k(H_\nu)\right|
\le \|E(T)\|_2.
```

Applying this to the largest and smallest eigenvalues yields the two asymptotic formulas. Dividing `K_Q(T)` by `T^{nu+1}` produces a Hermitian matrix that differs from `H_nu/(nu+1)!` by `O(T)`. For a simple separated extremal eigenvalue, a standard Hermitian eigenspace perturbation estimate (Davis–Kahan) then gives an `O(T)` angle. ∎

We call

```math
\nu=\min\{j\ge0:H_j\ne0\}
```

the **transport-generation order** of the admissible input space for `(A,Q,R)`.

## 5. Corollary T1-N: transport-neutral admissible inputs

Suppose every admissible initial condition is transport-neutral:

```math
B^\dagger Q B=0.
```

Equivalently, `H_0=0`. If

```math
H_1=R^{-1/2}B^\dagger(A^\dagger Q+QA)BR^{-1/2}\ne0,
```

then `nu=1` and

```math
\gamma_+(T)=\frac{T^2}{2}\lambda_{\max}(H_1)+O(T^3),
```

```math
\gamma_-(T)=\frac{T^2}{2}\lambda_{\min}(H_1)+O(T^3).
```

At the level of instantaneous transport,

```math
q(t;u)
=t\,u^\dagger B^\dagger(A^\dagger Q+QA)Bu+O(t^2),
```

because the initial term `u†B†QBu` vanishes identically.

### Interpretation

The leading transport is not inserted through an initially optimal cross-phase. It is generated by the dynamics through the first Lie/Lyapunov derivative of the physical signed transport form.

For a Hermitian form `Q`, the condition `B†QB=0` means that `range(B)` is a **totally Q-isotropic subspace**. This is standard indefinite-inner-product terminology; the terminology itself is not a novelty claim.

## 6. Corollary T1-P: a sharp distinction from positive-semidefinite output energy

Suppose instead that

```math
Q\succeq0
```

and still

```math
B^\dagger Q B=0.
```

Then

```math
Q^{1/2}B=0
```

and hence

```math
QB=0, \qquad B^\dagger Q=0.
```

Therefore not only `H_0=0` but also

```math
H_1=0.
```

Moreover,

```math
B^\dagger \mathcal L_A^2(Q)B
=2B^\dagger A^\dagger QAB,
```

so

```math
K_Q(T)
=\frac{T^3}{3}
R^{-1/2}B^\dagger A^\dagger QABR^{-1/2}
+O(T^4).
```

The leading matrix is positive semidefinite.

### Consequence

A transport-neutral subspace for an **indefinite signed transport form** can have `QB != 0` and therefore exhibit an `O(T^2)` accumulated signed-transport onset. A positive-semidefinite output energy/semi-norm cannot: initial neutrality forces the first derivative term to vanish, and the accumulated output begins no earlier than `O(T^3)`.

This order distinction is one of the reasons the project must preserve the actual indefinite cross-term structure of physical flux observables rather than replace them by sums of squared state amplitudes.

## 7. Corollary T1-C: coordinate invariance of the generation matrices

Let `x' = Sx` with invertible `S`, and transform

```math
A'=SAS^{-1},
Q'=S^{-\dagger}QS^{-1},
B'=SB.
```

Then for every `j >= 0`,

```math
\mathcal L_{A'}^j(Q')
=S^{-\dagger}\mathcal L_A^j(Q)S^{-1}.
```

Consequently,

```math
B'^\dagger\mathcal L_{A'}^j(Q')B'
=B^\dagger\mathcal L_A^j(Q)B,
```

and therefore `H_j`, the transport-generation order `nu`, and the leading signed extremal coefficients are invariant under invertible state-coordinate changes.

### Proof

The formula is immediate for `j=0`. If it holds for `j`, then

```math
\mathcal L_{A'}(S^{-\dagger}XS^{-1})
=A'^\dagger S^{-\dagger}XS^{-1}
+S^{-\dagger}XS^{-1}A'
=S^{-\dagger}(A^\dagger X+XA)S^{-1}.
```

Induction proves the first identity. Substitution of `B'=SB` proves the projected identity. ∎

## 8. Stable 2 x 2 analytic witness

Take real matrices

```math
A=\begin{bmatrix}-1&0\\ \kappa&-2\end{bmatrix},
\qquad
Q=\frac12\begin{bmatrix}0&1\\1&0\end{bmatrix},
\qquad
B=\begin{bmatrix}1\\0\end{bmatrix},
\qquad R=1.
```

For `kappa != 0`, `A` is nonnormal and has stable eigenvalues `-1` and `-2`. The admissible initial state is transport-neutral because

```math
B^TQB=0.
```

However,

```math
B^T(A^TQ+QA)B=\kappa.
```

The exact trajectory for unit input is

```math
x_1(t)=e^{-t},
\qquad
x_2(t)=\kappa(e^{-t}-e^{-2t}),
```

and the physical cross-form evaluates to

```math
q(t)=x_1(t)x_2(t)
=\kappa(e^{-2t}-e^{-3t}).
```

Thus

```math
J_Q(T)
=\kappa\left[
\frac{1-e^{-2T}}{2}
-\frac{1-e^{-3T}}{3}
\right]
=\frac{\kappa}{2}T^2+O(T^3).
```

This is a minimal analytic benchmark for the later JAX test suite. It is not yet a plasma model and is not evidence for physical novelty by itself.

## 9. What this theorem does and does not establish

### Established

1. The short-time expansion is exact and analytic in finite dimension.
2. A transport-neutral admissible subspace removes the trivial `O(T)` accumulated term.
3. The first nonzero projected Lyapunov derivative determines the short-time signed optimals.
4. The leading generation matrices are coordinate invariant.
5. Indefinite signed transport and positive-semidefinite output energy have structurally different possible onset orders under initial neutrality.

### Not established

1. That T1-G is mathematically novel in the abstract.
2. That a physically meaningful plasma input space satisfying `B†QB=0` exists for the final chosen convention.
3. That `H_1` is nonzero in the Hasegawa–Wakatani pilot.
4. That the short-time transport optimal differs from the free-energy optimal over a robust parameter interval.
5. Any infinite-dimensional extension.
